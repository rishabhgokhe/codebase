# 📊 Aptitude Preparation

This folder contains preparation material for **Quantitative Aptitude, Logical Reasoning, and Verbal Ability**, which are essential for clearing placement tests.

## 🎯 Focus Areas
- Quantitative Aptitude (Arithmetic, Algebra, Probability)
- Logical & Analytical Reasoning
- Verbal Ability & Reading Comprehension

## 📌 Goal
To build **speed, accuracy, and problem-solving skills** required for online assessments and aptitude rounds.
